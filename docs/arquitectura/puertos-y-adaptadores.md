# Catálogo de puertos y adaptadores

Todo puerto o adaptador nuevo o modificado se registra aquí en el mismo cambio que lo introduce (Const. 14). Los nombres del código están en inglés; entre paréntesis, el nombre del plan. Las rutas son relativas a `apps/backend/src`.

## Puertos compartidos

| Puerto                                     | Ubicación                                 | Para qué                                                                                                                      | Adaptadores                                                            |
| :----------------------------------------- | :---------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------- |
| `Clock` (Reloj)                            | `compartido/aplicacion/clock.ts`          | Hora actual. Los casos de uso nunca leen la hora del sistema directamente.                                                    | `systemClock`; `ManualClock` en pruebas                                |
| `IdGenerator` (GeneradorDeId)              | `compartido/aplicacion/id-generator.ts`   | Identificadores UUID generados por el backend.                                                                                | `uuidGenerator`                                                        |
| `UnitOfWork` (UnidadDeTrabajo)             | `compartido/aplicacion/unit-of-work.ts`   | Transacción: todo se confirma junto o nada. Fija el comercio de la sesión para la seguridad a nivel de fila.                  | `PgDatabase`                                                           |
| `JobScheduler`                             | `compartido/aplicacion/job-scheduler.ts`  | Programar trabajos en segundo plano, idempotentes por tipo y clave (AD-19).                                                   | `PgJobScheduler`                                                       |
| `EventOutbox`                              | `compartido/aplicacion/event-outbox.ts`   | Escribir eventos en la misma transacción que el cambio que los origina (AD-07).                                               | `PgEventOutbox`                                                        |
| `Logger`                                   | `compartido/aplicacion/logger.ts`         | Registrar eventos y errores.                                                                                                  | `createPinoLogger`; `createMemoryLogger` en pruebas                    |
| `AccessTokens` (EmisorDeTokens)            | `compartido/aplicacion/access-tokens.ts`  | Emitir y verificar tokens de acceso de vida corta con el contexto de seguridad (AD-11).                                       | `JoseAccessTokens`                                                     |
| `TechnicalAuditLog`                        | `compartido/aplicacion/audit.ts`          | Auditoría técnica de plataforma: ingresos, accesos denegados, bloqueos (RF-022). Se registra aunque la operación se revierta. | `PgTechnicalAuditLog`                                                  |
| `CommercialAuditLog` (RegistroDeAuditoria) | `compartido/aplicacion/audit.ts`          | Auditoría comercial, en la misma transacción que la operación (RF-018, AD-10).                                                | `PgCommercialAuditLog`                                                 |
| `EmailSender` (EnvioDeCorreo)              | `compartido/aplicacion/email-sender.ts`   | Enviar correos de validación y recuperación.                                                                                  | `ConsoleEmailSender` (solo desarrollo); `MemoryEmailSender` en pruebas |
| `ResourceOwnership`                        | `compartido/aplicacion/access-control.ts` | Comercio dueño de un registro, sin devolver sus datos: para responder "no existe" y registrar el intento (RF-002).            | `PgResourceOwnership`                                                  |

## Núcleo de seguridad (aplicación compartida)

| Pieza              | Ubicación                                   | Qué hace                                                                                                                                                        |
| :----------------- | :------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SecurityContext`  | `compartido/aplicacion/security-context.ts` | Usuario, comercio, rol activo, sucursales y sesión, tomados siempre del token (T-035, RF-001).                                                                  |

## Adaptadores de entrada

| Adaptador              | Ubicación                                               | Qué hace                                                                                                                                                                          |
| :--------------------- | :------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Aplicación HTTP        | `app.ts`, `server.ts`, `composition.ts`                 | Raíces de composición de la API. `composition.ts` arma módulos y adaptadores, y falla al arrancar con una configuración insegura (por ejemplo, correo por consola en producción). |
| Registro de rutas      | `compartido/adaptadores/http/routes.ts`                 | Toda ruta es protegida por defecto; solo puede ser pública con un motivo de la lista blanca de AD-22.                                                                             |
| Autenticación HTTP     | `compartido/adaptadores/http/authentication.ts`         | Verifica el token de acceso de toda solicitud que no sea pública, incluidas las rutas inexistentes (Const. 16).                                                                   |
| Validación de entradas | `compartido/adaptadores/http/validation.ts`             | Valida cuerpos y parámetros con zod, sin repetir los valores recibidos en el error (Const. 17).                                                                                   |
| Seguridad HTTP         | `compartido/adaptadores/http/security.ts`               | Cabeceras de seguridad, CORS limitado al frontend y límite del cuerpo JSON (T-016). Las rutas públicas tienen límite de frecuencia por IP (`app.ts`).                             |
| Errores HTTP           | `compartido/adaptadores/http/errors.ts`                 | Convierte errores en `{codigo, mensaje}` sin detalles internos (T-015).                                                                                                           |
| Documentación          | `compartido/adaptadores/http/docs.ts`                   | Swagger UI en `/docs`, solo en desarrollo (T-013).                                                                                                                                |
| Proceso worker         | `worker.ts`                                             | Raíz de composición del worker: ejecuta trabajos programados y despacha el outbox. `npm run worker`.                                                                              |
| `PgJobWorker`          | `compartido/adaptadores/jobs/pg-job-worker.ts`          | Toma trabajos con `FOR UPDATE SKIP LOCKED`, reintenta con espera creciente y retoma los abandonados (T-021).                                                                      |
| `PgOutboxDispatcher`   | `compartido/adaptadores/outbox/pg-outbox-dispatcher.ts` | Entrega cada evento a su manejador y lo marca procesado en la misma transacción. Nunca descarta un evento (T-022).                                                                |

## Seguridad a nivel de fila

La migración `aislamiento_por_comercio` define la política plantilla: una tabla comercial se aísla con `SELECT aplicar_aislamiento_por_comercio('tabla')`. Hoy la usan `auditoria_comercial`, `credencial_autorizacion` y `autorizacion`. Las tablas de plataforma e identidad (`comercio`, `usuario`, `usuario_rol`, tokens, intentos, `auditoria_tecnica`, `trabajo_programado`, `outbox`) no la usan.
